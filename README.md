# AD-Reverse-Password-Sync

**Active Directory Reverse Password Synchronization for midPoint**

A tool that captures password changes in **Active Directory** and automatically forwards them to **midPoint**, enabling password synchronization.

---

## Features

- Real-time password change capture in Active Directory
- Automatic synchronization with midPoint via REST API
- Secure credential handling
- Windows installer
  
---

## Technologies

- **C#**
- **C**

---

## Installation

### Prerequisites

- Windows Server with **Active Directory Domain Services**
- **midPoint** installed and running

### Installation (Recommended)

1. Download the latest release:
    → [AD-ReverseSync-1.0.6.exe](https://github.com/eBZtec/AD-Reverse-Password-Sync/releases)

2. Run the installer as **Administrator**

3. Follow the installation wizard
    → Fill in the **midPoint** URL, association attribute and user credentials
    
4. Configure midPoint resources
